# Яндекс.Почта — очистка (Yandex Mail Cleaner)

Простое приложение для Windows, которое переносит письма Яндекс.Почты в **Корзину**
по выбранным фильтрам: папки, период, размер. Письма остаются восстановимыми.

Полное техническое задание — в [SPEC.md](SPEC.md).

## Готовый файл

```
dist\YandexMailCleaner.exe
```

Один файл, ~71 МБ, self-contained — запускается на Windows 10/11 x64 **без установки .NET**.
Именно этот файл нужно копировать на компьютеры пользователей.

> Важно: не используйте `YandexMailCleaner.exe` из папки `bin\...\win-x64\` — это
> промежуточная сборка, которой рядом нужен `.dll`. Раздавать нужно только файл из `dist\`
> (или из `publish\`).

## Что умеет

- Подключение к `imap.yandex.ru` по IMAP (SSL).
- Выбор одной или нескольких папок (Входящие, Спам, Отправленные и т.д.).
- Фильтр по дате: старше 1/3/6/12 месяцев, всё время или произвольный период.
- Фильтр по размеру: письма больше указанного количества МБ.
- Подтверждение с количеством найденных писем, затем перенос в Корзину.
- Пароль приложения вводится один раз на компьютере и запоминается (DPAPI).
- Подробный журнал операций по шагам.

## Требования

- Windows 10/11, x64.
- Включённый доступ по IMAP в настройках Яндекс.Почты.
- **Пароль приложения** (обычный пароль аккаунта для IMAP не подходит).
- Аккаунт должен быть в домене `yandex.ru`.

### Как получить пароль приложения

1. Откройте <https://id.yandex.ru> и войдите в аккаунт.
2. «Безопасность» → «Пароли приложений» → создайте пароль для «Почты».
3. Скопируйте пароль.
4. В Почте: «Все настройки» → «Почтовые программы» → включите доступ по IMAP.

## Использование

1. Запустите `dist\YandexMailCleaner.exe` (установка не нужна).
2. Введите email `...@yandex.ru` и пароль приложения, нажмите «Подключиться».
3. Отметьте папки, выберите период и при необходимости минимальный размер.
4. Нажмите «Переместить в Корзину» и подтвердите действие.
5. Проверить результат можно на <https://mail.yandex.ru> (папка «Корзина»).

При следующих запусках на этом же компьютере подключение происходит автоматически —
пароль повторно не запрашивается. Для смены ящика используйте «Сменить аккаунт».

## Устойчивость соединения

Яндекс закрывает простаивающее IMAP-соединение примерно через 90 секунд. Поэтому:

- приложение отправляет служебный «пульс» (NOOP) каждые 25 секунд, пока подключено;
- перед поиском и перемещением проверяет соединение и при необходимости переподключается;
- при обрыве во время поиска один раз повторяет операцию после переподключения;
- на каждую операцию есть тайм-аут, чтобы окно не «висело» бесконечно;
- во время длительной операции доступна кнопка «Отмена».

## Где хранятся данные

`%AppData%\YandexMailCleaner\`

- `account.dat` — email и пароль приложения, зашифрованные DPAPI (текущий пользователь).
- `settings.json` — последние выбранные фильтры.
- `logs\cleaner-ГГГГММДД.log` — журнал: подключение, поиск, найденное количество,
  переподключения, ошибки.

Шифрование привязано к компьютеру и пользователю Windows: при копировании `.exe`
на другой ПК пароль не переносится, его нужно ввести один раз заново.

## Если что-то не работает

1. Посмотрите журнал: `%AppData%\YandexMailCleaner\logs\cleaner-ГГГГММДД.log`.
2. Проверьте, что запускается файл из `dist\` (а не промежуточный из `bin\`).
3. Убедитесь, что используется пароль приложения, а в настройках почты включён IMAP.
4. При ошибке «Неверный email или пароль приложения» удалите сохранённые данные
   кнопкой «Сменить аккаунт» и введите пароль заново.

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (только на компьютере
разработчика; на целевых ПК ничего ставить не нужно).

```powershell
cd src\YandexMailCleaner
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Готовый файл:
`src\YandexMailCleaner\bin\Release\net8.0-windows\win-x64\publish\YandexMailCleaner.exe`
(скопируйте его в `dist\`).

## Структура проекта

```
src/YandexMailCleaner/
  App.xaml(.cs)               — точка входа
  MainWindow.xaml(.cs)        — интерфейс и сценарий работы
  Models/                     — параметры очистки, папки, результаты
  Services/
    ImapService.cs            — IMAP: подключение, keep-alive, поиск, перенос в Корзину
    CredentialStore.cs        — DPAPI-хранилище email и пароля приложения
    SettingsStore.cs          — последние фильтры
    AppLogger.cs              — журнал
    AppPaths.cs               — пути %AppData%
```

## Ограничения

- Только домен `yandex.ru`.
- Только перенос в Корзину (без безвозвратного удаления и очистки Корзины).
- Без предпросмотра списка писем: после поиска показывается количество.
- Общий объём найденных писем не подсчитывается (чтобы не тормозить на больших ящиках);
  фильтр «больше N МБ» при этом работает на стороне сервера.
