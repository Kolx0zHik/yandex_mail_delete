# ТЗ: «Яндекс.Почта — очистка» (Yandex Mail Cleaner)

## 1. Назначение
Простое десктопное приложение для бухгалтеров. Подключается к ящику Яндекс.Почты по IMAP
и переносит в Корзину письма по выбранным критериям (дата, папка, размер).
Сценарий использования — разовый запуск: выбрал параметры → нажал кнопку → письма в Корзине.

## 2. Платформа и формат поставки
- Windows 10/11, x64.
- Один portable `.exe` — без установки и без сторонних рантаймов на целевом ПК (self-contained).
- Приложение копируется на несколько компьютеров; каждый ПК хранит свои данные отдельно.
- Права администратора не требуются. Интерфейс полностью на русском.
- Готовый файл: `dist\YandexMailCleaner.exe` (~71 МБ).

## 3. Технологический стек
- C# / .NET 8, WPF — нативный оконный интерфейс.
- MailKit 4.18.1 — IMAP-клиент.
- Публикация одним файлом:
  `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`

## 4. Подключение и аутентификация
- IMAP-сервер: `imap.yandex.ru`, порт `993`, SSL/TLS.
- Домен: только `yandex.ru`.
- Логин: полный email (вида `user@yandex.ru`).
- Пароль: **пароль приложения** (обычный пароль Яндекс.Почты для IMAP не подходит).
- В приложение встроена инструкция «Как получить пароль приложения»:
  Яндекс ID → Безопасность → Пароли приложений → создать пароль;
  в настройках почты должен быть разрешён доступ по IMAP.

## 5. Хранение пароля и безопасность
- При первом запуске на ПК пользователь вводит email + пароль приложения.
- Пароль шифруется DPAPI (в рамках текущего пользователя Windows) и сохраняется в
  `%AppData%\YandexMailCleaner\`.
- Повторно программа пароль **не спрашивает** — при следующих запусках подключение автоматически.
- Кнопка «Сменить аккаунт» сбрасывает сохранённые данные и позволяет ввести их заново.
- Шифрование привязано к ПК/пользователю: при копировании `.exe` на другой компьютер
  сохранённый пароль не переносится, поэтому там он вводится заново один раз. Это безопасно.

## 6. Сценарий работы (UX)
1. **Экран подключения** (только при первом запуске на этом ПК): email, пароль приложения,
   кнопка «Подключиться», ссылка-инструкция.
2. **Главный экран (мастер очистки):**
   - **Папки** — список загружается с сервера (Входящие, Спам, Отправленные, Корзина и др.),
     можно выбрать несколько. По умолчанию — Входящие.
   - **Фильтр по дате**: «Старше: 1 мес / 3 мес / 6 мес / 1 год / всё» либо «Период с __ по __».
   - **Фильтр по размеру**: «Не важен» либо «Больше __ МБ».
   - Кнопка **«Переместить в Корзину»**.
3. **Подтверждение**: программа выполняет поиск и показывает диалог
   «Найдено писем: N. Переместить их в Корзину?». Предпросмотр отдельных писем не делается —
   бухгалтер при необходимости посмотрит Корзину через веб-интерфейс Яндекса.
4. **Выполнение**: прогресс-бар и текст текущего шага, кнопка «Отмена», затем итог
   «Готово. Перемещено писем: N».

## 7. Критерии отбора (реализация)
- Поиск на стороне сервера через IMAP `SEARCH` (`BEFORE`/`SINCE` по дате, `LARGER` по размеру).
- Тела писем и их размеры не скачиваются: возвращается только список UID.
- «Старше N месяцев» считается от даты получения (INTERNALDATE) до сегодня.
- Результат поиска сохраняется в виде UID, чтобы переместить именно то, что было посчитано.

## 8. Удаление
- Только перемещение в Корзину (письма восстановимы из веб-интерфейса Яндекса).
- Используется IMAP-команда `MOVE` в папку со специальным назначением `\Trash`.
- Перемещение выполняется пакетами по 200 писем (прогресс и устойчивость к тайм-аутам).
- Режим «удалить навсегда» не реализуется.

## 9. Устойчивость соединения (важно)
- Яндекс закрывает простаивающее IMAP-соединение примерно через 90 секунд.
- После подключения приложение отправляет NOOP каждые 25 секунд.
- Перед поиском и перемещением выполняется проверка соединения и автопереподключение.
- При обрыве во время поиска операция один раз повторяется после переподключения.
- Каждая операция ограничена тайм-аутом (подключение 30 с, папки 60 с, поиск 180 с,
  пакет перемещения 120 с), чтобы интерфейс не зависал.
- Длительную операцию можно отменить кнопкой «Отмена».

## 10. Журнал и ошибки
- Лог операций в `%AppData%\YandexMailCleaner\logs\` с шагами: подключение, старт очистки,
  запрос поиска, найденное количество и время, переподключения, ошибки.
- Сообщения об ошибках на русском: неверный пароль, IMAP-доступ выключен, нет сети,
  тайм-аут, обрыв соединения.

## 11. Прочее
- Приложение запоминает последние выбранные фильтры между запусками.
- Имя файла: `YandexMailCleaner.exe`, распространяется из папки `dist\`.

## 12. Границы решения (не делаем)
- Поддержка доменов, отличных от `yandex.ru`.
- Безвозвратное удаление (EXPUNGE) и очистка Корзины.
- Предпросмотр/список отдельных писем, выборочные галочки по письмам.
- Подсчёт общего объёма найденных писем (фильтр по размеру при этом работает).
- Консольный или веб-вариант; планировщик/автозапуск.
